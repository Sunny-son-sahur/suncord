SUNCORD

A lightweight Discord client modification with a built-in store for plugins and themes. Install by dragging a zip file, or browse the online store.

Download View Source
🏪

Built-in Store

Plugin and theme store right inside Discord. Browse, search, one-click install.

📦

Drag & Drop

Drop a .zip plugin or .css theme onto the store to install it instantly.

🔗

Vencord Compatible

Works with Vencord, BetterDiscord, and Powercord themes and plugins.

Download for Windows

Windows 10/11 • Installer or portable

suncord-setup.exe Windows Installer • Recommended
⬇ suncord-portable.zip — Portable (no install needed)

Installation

  1. Download and run suncord-setup.exe
  2. Click Install (or choose a custom path)
  3. Close Discord completely (check system tray)
  4. Launch Discord — the ☀ Store button appears in the top-right
⚠ Windows SmartScreen: Click "More info" then "Run anyway". This is a false positive — SUNCORD is open source and safe.

Download for Linux

Debian/Ubuntu • Fedora/RHEL • Any distro

suncord_1.0.0_amd64.deb Debian / Ubuntu / Linux Mint
⬇ suncord-portable.zip — Portable (any distro)

Installation (.deb)

  1. Download the .deb file
  2. Install: sudo dpkg -i suncord_1.0.0_amd64.deb
  3. Fix deps if needed: sudo apt-get install -f
  4. Run: suncord.sh launch

From Source

  1. git clone https://github.com/Sunny-son-sahur/suncord.git
  2. cd suncord && npm install && npm run build
  3. bash scripts/suncord.sh install
  4. Launch Discord — done!

Download for Mac

macOS 12+ • From source

suncord-portable.zip Portable • Works on macOS
⬇

Installation

  1. Install Node.js from nodejs.org
  2. git clone https://github.com/Sunny-son-sahur/suncord.git
  3. cd suncord && npm install && npm run build
  4. node scripts/inject.mjs
  5. Launch Discord — the Store button appears!
⚠ macOS Gatekeeper: If you get "app can't be opened", right-click the app and select Open. Or go to System Settings > Privacy & Security and click "Allow Anyway".
